# VenomBrt · Portfolio

Portfolio do VenomBrt, fundador do Recreate Studios: mods, plugins e launchers para Minecraft, além de sites.

**Acesse:** https://venombrt.github.io

## Como editar

Todo o conteúdo fica em `js/dados.js` (perfil, habilidades, projetos e galeria).
Imagens vão em `assets/images/` e vídeos em `assets/videos/`.

Feito com HTML, CSS e JavaScript puro, hospedado no GitHub Pages.
